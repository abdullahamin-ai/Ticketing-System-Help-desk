# Help Desk Frontend

Production-ready React + TypeScript frontend for the Help Desk / Ticketing System FastAPI backend.

## Tech Stack

- **React 18** + **TypeScript**
- **Vite** (build tool)
- **Tailwind CSS** (styling)
- **Axios** (API client)
- **React Router** (routing)
- **Zustand** (state management)
- **react-hot-toast** (notifications)
- **lucide-react** (icons)
- **date-fns** (date formatting)
